Política de Privacidade

Última atualização: julho de 2026

Este documento é um modelo de referência e ainda não passou por revisão jurídica. Antes de considerá-lo definitivo, recomendamos que um advogado especializado em proteção de dados (LGPD) revise o conteúdo de acordo com a operação real da LDFP.

Esta Política de Privacidade descreve como a LDFP - Liderança com Propósito ("LDFP", "nós") coleta, usa, armazena e protege os dados pessoais tratados através do sistema de gestão de igrejas disponível em ldfp.com.br ("Sistema").

1. Quem trata os dados

O Sistema é oferecido no modelo SaaS (Software as a Service): cada igreja cliente ("Cliente") é responsável pelos dados que cadastra sobre seus próprios membros, visitantes, dízimos e demais registros. A LDFP atua como operadora desses dados, processando-os em nome do Cliente, conforme suas instruções e finalidades definidas por ele.

2. Quais dados são coletados

Dependendo dos módulos utilizados pelo Cliente, o Sistema pode tratar:

  • Dados de identificação: nome, CPF, RG, data de nascimento, sexo, estado civil, foto;
  • Dados de contato: e-mail, telefone, celular, endereço completo;
  • Dados eclesiásticos: cargo, situação de membresia, histórico pastoral, congregação, grupo/célula;
  • Dados financeiros: dízimos, ofertas, lançamentos de caixa, contas bancárias vinculadas à igreja;
  • Dados de uso: login, permissões de acesso e registros de auditoria do Sistema.

3. Finalidade do tratamento

Os dados são utilizados exclusivamente para viabilizar as funcionalidades contratadas pelo Cliente: gestão de membros e congregações, controle financeiro e contábil, escalas, comunicação (ex.: WhatsApp) e emissão de relatórios internos da própria igreja.

4. Compartilhamento de dados

A LDFP não vende nem compartilha dados pessoais com terceiros para fins de marketing. Dados podem ser compartilhados apenas com prestadores de infraestrutura estritamente necessários à operação do Sistema (ex.: hospedagem, banco de dados), sob obrigação contratual de confidencialidade.

5. Armazenamento e segurança

Os dados são armazenados em banco de dados isolado por igreja cliente (multi-tenant), com controle de acesso por autenticação e permissões de papel (perfil de usuário). Adotamos medidas técnicas razoáveis para proteger os dados contra acesso não autorizado, perda ou alteração indevida.

6. Direitos do titular

Nos termos da Lei Geral de Proteção de Dados (Lei nº 13.709/2018), o titular dos dados pode solicitar à sua igreja (Cliente, responsável pelo cadastro) a confirmação, acesso, correção, anonimização ou eliminação de seus dados pessoais, bem como informações sobre o compartilhamento realizado.

7. Retenção e exclusão

Os dados são mantidos enquanto durar o vínculo contratual entre o Cliente e a LDFP. Ao encerrar a assinatura, o Cliente pode solicitar a exportação ou exclusão definitiva dos dados de sua igreja, observados prazos legais de guarda quando aplicáveis (ex.: registros contábeis e financeiros).
